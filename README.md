# 红楼一梦 · 网页版

整本《红楼梦》装进一个小工具（网页版复刻）。

- 两个底本：脂评本八十回（含 4000+ 条脂批落位）、程乙本一百二十回，一键切换
- 一个框全能搜：人物 · 诗词 · 吃食 · 药方 · 事件 · 脂批 · 原文
- 人物关系图：点谁，就以谁为中心铺开，每条关系标着第几回
- 诗词 / 吃食 / 药方：每一样附原文出处
- 大事记：按回排好，点开就跳原文
- 人物卡片：canvas 生成，可保存 PNG

## 数据说明

- 程乙本一百二十回：公开语料整理
- 脂评本八十回及脂批：基于公开的脂评汇校排版本整理（批语按原文落位）
- 人物关系：基于公开知识图谱数据集（KGQA_HLM 等）整理
- 诗词 / 吃食 / 药方 / 大事：人工精选整理

灵感来自小红书 @浮生小记 的「红楼一梦」小工具，本项目为其网页版功能复刻，数据均为公开语料。
